## 🛠️ 编译环境说明

- **IDE**：Android Studio (最新版推荐)
- **构建工具**：Gradle 9.x / Android Gradle Plugin
- **JDK**：Java 17 / Java 21 (JBR)
- **编译方式**：直接导入 Android Studio 点击 `Sync Project with Gradle Files` 即可一键直接编译。
